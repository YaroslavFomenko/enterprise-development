# CarWash — Автомойка

## Описание предметной области

В базе данных автомойки содержится информация об услугах, клиентах и заказах на обслуживание автомобилей.

### Сущности

- **Услуга** — название, категория автомобиля, стоимость, длительность в минутах
- **Клиент** — ФИО, телефон, может иметь несколько автомобилей
- **Автомобиль** — госномер, марка, категория
- **Заказ** — клиент, услуга, автомобиль, дата и время начала, номер бокса

## Технологии

- .NET 10
- xUnit v3
- GitHub Actions

## Аналитические запросы

1. Топ-5 клиентов по количеству посещений
2. Автомобили, находящиеся на мойке в данный момент
3. Топ-5 наиболее популярных услуг
4. Время освобождения выбранного бокса
5. Суммарная выручка по каждой услуге
